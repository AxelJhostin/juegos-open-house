# Estudios de caminata de Naomi

Estos archivos son pruebas de movimiento, no sprites listos para el juego. En las imágenes generadas, varias poses repiten el mismo apoyo y algunas partes se cortan al dividir la hoja.

## Vistas para explorar

- [Prueba de cuatro cuadros](vista-caminar.html): primer estudio con poses más diferenciadas.
- [Prueba de ocho cuadros](vista-ocho-cuadros-borrador.html): usa `estudio-ocho-pasos-v3.png`; contiene cortes y pasos repetidos.
- La [guía de 30 cuadros](../referencia-diseno/guia-caminata-30.html) muestra un esquema de piernas, no el personaje animado.

## Archivos de trabajo

- `caminar-4-cuadros-borrador.png` y `estudio-perfil-6-poses.png`: primeros intentos de vista lateral.
- `estudio-ocho-cuadros-seria.png`, `estudio-ocho-pasos-v2.png` y `estudio-ocho-pasos-v3.png`: estudios de ocho poses. El último también se conserva como copia exacta en `../referencia-diseno/` para fijar el aspecto aprobado.
- `estudio-caminata-con-guia-borrador.png`, `estudio-contactos-borrador.png` y `estudio-paso-individual-borrador.png`: intentos posteriores para corregir la alternancia.
- `prueba-apoyo-a-no-validada.png` y `prueba-apoyo-b-no-validada.png`: pruebas individuales de apoyo; no lograron mostrar correctamente las dos piernas alternando.

Las vistas conservan sus rutas e imágenes originales para que los enlaces anteriores sigan funcionando.
